# Train livery sources
- livery-green / livery-red / livery-blue: AI-generated side-elevation photos (locomotive + one coach in a single image), generated 2026-10-21 for this app.
- Deployed textures: assets/train_<name>_loco.jpg / train_<name>_car.jpg (1024x256). Split at the coupling by column-density minimum; bottom wheel band mostly excluded so the app's own underframe/wheels show.
- In-app: swapped onto the car body side materials; drawn window strips hidden while a photo livery is active. Button "기차:" cycles classic / express / vintage / default drawn.
