# Panorama source
- rockies-pano: AI-generated equirectangular landscape (Canadian Rockies valley), generated 2026-10-21 for this app.
- Deployed file: assets/pano_rockies.jpg (2048x1024, resized from the 2240x1120 original kept here).
- In-app: mirrored-repeat wrap (repeat.x = 2) on a camera-following cylinder, shown in MEADOW/FOREST biomes.
- pano-desert: AI-generated desert sunset panorama (this project, 2026-10-21). Deployed as assets/pano_desert.jpg (bottom 8% cropped, 2048x1024). Used for DESERT biome backdrop + sunset env.
- pano-coast: AI-generated tropical coast panorama (this project, 2026-10-21). Deployed as assets/pano_coast.jpg (2048x1024). Used for COAST biome backdrop.
