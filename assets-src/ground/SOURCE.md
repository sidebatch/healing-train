# Ground texture sources
- ground_meadow / ground_forest: AI-generated top-down aerial ground textures, generated 2026-10-21 for this app.
- Deployed files: assets/ground_meadow.jpg, assets/ground_forest.jpg (1024x1024, from 1600x1600 originals kept here).
- In-app: mirrored-repeat wrap on the dream-mode terrain material for MEADOW / FOREST biomes.
- ground_field: AI-generated aerial farmland texture; deployed crop uses the crop-rows region only (dirt band excluded). Applied to all field materials.
- ground-desert: AI-generated top-down rippled sand texture (2026-10-21) -> assets/ground_desert.jpg (1024x1024, brightness +13% to offset vertex-color multiply).
- ground-coast: AI-generated top-down beach sand + dune grass texture (2026-10-21) -> assets/ground_coast.jpg (same treatment).
