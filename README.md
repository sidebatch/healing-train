# 어디든 가는 기차 (Healing Train)

켜놓고 멍하니 보기 좋은 힐링 앱. 6량짜리 기차가 끝없이 이어지는 레일을 따라 어딘가로 계속 달린다.
레일은 일직선이 아니라 지형을 따라 굽이치고 오르내리며, 풍경은 구간마다 다른 컨셉으로 계속 바뀐다.

## 바로 보기

**▶ https://sidebatch.github.io/healing-train/** (3D 버전, 메인)

- 2D 아이소메트릭 버전: https://sidebatch.github.io/healing-train/iso.html
- 2D 옆면 버전 (초기 프로토타입): https://sidebatch.github.io/healing-train/side-view.html

## 맵 (8개 컨셉)

초원 · 숲 · 산 · 바다 · 사막 · 눈 내리는 마을 · 설산 · 밤하늘

- 가만히 두면 구간이 자동으로 바뀌며 계속 이어진다.
- 화면 아래 맵 버튼을 누르면 원하는 맵으로 바로 이동한다.
- 설산과 산 구간에서는 선로 자체가 높은 곳으로 올라가고, 눈 마을과 설산에서는 눈이 내린다.
- 밤에는 별이 뜨고, 집 창문과 기차 전조등에 불이 켜진다.

## 조작

- **카메라**: 영화(천천히 도는 시점) · 옆에서 · 기관실 · 위에서 — 버튼으로 전환
- **속도**: 0.5배 · 1배 · 1.7배
- **소리**: 바람의나라·테일즈위버 분위기의 잔잔한 패드 사운드 켜기/끄기
- **멈추기/계속 가기**, 경과 시간 타이머, 재생 중 화면 꺼짐 방지

## 기술

- 실시간 3D 렌더링: [Three.js](https://threejs.org/) r128 (리포에 자체 호스팅, `assets/three.min.js`)
- 청크 단위로 생성되는 무한 지형, 굽이치는 레일 경로 함수 기반 배치
- 실시간 햇빛과 그림자, 안개, 하늘 그라데이션, 컨셉 간 색상 블렌딩
- 단일 HTML 파일들로 구성 (빌드 과정 없음)
