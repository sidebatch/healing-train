# 어디든 가는 기차 (Healing Train)

켜놓고 멍하니 보기 좋은 힐링 앱. 6량짜리 기차가 끝없이 이어지는 레일을 따라 어딘가로 계속 달린다.
레일은 일직선이 아니라 지형을 따라 굽이치고 오르내리며, 풍경은 구간마다 다른 컨셉으로 계속 바뀐다.

## 바로 보기

**▶ https://sidebatch.github.io/healing-train/** (3D 버전, 메인)

- 2D 아이소메트릭 버전: https://sidebatch.github.io/healing-train/iso.html
- 2D 옆면 버전 (초기 프로토타입): https://sidebatch.github.io/healing-train/side-view.html

## 앱으로 설치 (PWA)

폰 브라우저에서 위 주소를 열고 메뉴에서 **앱 설치** 또는 **홈 화면에 추가**를 누르면 아이콘이 생기고 전체 화면 앱처럼 실행된다. 오프라인에서도 열린다 (서비스워커 캐시). 소리는 브라우저 정책상 자동 재생이 안 돼서, 아래쪽 **소리 켜기** 버튼을 한 번 눌러야 시작된다.

## 실제 노선 모드 (캐나다 로키)

맵 버튼 맨 앞의 **실제 노선**을 누르면, 가상의 풍경이 아니라 실제 장소를 달린다. (2026-10-23부터 버튼을 숨겨 두었다 — 코드는 남아 있다)

- 노선: 캐나다 로키의 실제 철길 **CPKC 라간 선 (Laggan Subdivision)** — 레이크 루이스 역에서 모란트 커브, 캐슬 정션을 지나 밴프, 캔모어까지 **83km**
- 선로 위치는 OpenStreetMap의 실제 철도 데이터, 지형 높이는 실제 표고 데이터(AWS Terrain Tiles)를 그대로 사용 — 보우 밸리의 실제 골짜기와 경사를 따라 오르내린다 (레이크 루이스 약 1,560m → 캔모어 약 1,310m로 계속 내려가는 실제 노선)
- 실제 지명을 지날 때마다 화면에 안내가 뜬다. 종점에 닿으면 방향을 바꿔 왕복한다.
- 지면은 실제 지형의 형태에 색을 입힌 것이고, 위성 사진 지면은 다음 단계로 준비 중이다.

데이터 출처: 지도 © OpenStreetMap contributors (ODbL), 지형 AWS Terrain Tiles (Mapzen 지형 데이터). 하늘 사진은 Poly Haven (CC0), 풍경 모델은 Quaternius (CC0).

## 맵 (8개 컨셉)

초원 · 숲 · 바다 · 사막 · 노을 호수 · 눈 내리는 마을 · 설산 · 밤하늘

- 가만히 두면 구간이 자동으로 바뀌며 계속 이어진다.
- 화면 아래 맵 버튼을 누르면 원하는 맵으로 바로 이동한다.
- 맵마다 지형과 구성이 다르다: 초원의 논밭과 건초 더미, 빽빽한 숲, 사막의 모래언덕, 노을 호수, 눈 마을의 집 무리와 가로등, 설산의 바위와 얼음 호수, 밤의 달. 마을의 집은 사진 6종이 섞여 나온다.
- 설산 구간에서는 선로 자체가 높은 곳으로 올라가고, 눈 마을과 설산에서는 눈이 내린다.
- 초원·숲·사막에 이어 노을 호수·눈 내리는 마을·설산도 사진 파노라마 배경과 사진 지면으로 바뀌었다. 사막의 선인장과 눈 마을·설산의 소나무도 실사 사진 빌보드로 교체됐다. (해변 맵은 2026-10-23 사용자 결정으로 제거됨)
- 밤에는 별이 뜨고, 은하수가 가로지르며, 가끔 별똥별이 떨어진다. 집 창문과 기차 전조등에 불이 켜진다. 밤의 나무와 집도 장난감 같은 3D 모형이 아니라 낮과 같은 실사 사진으로 나온다. 이제 초원·숲을 뺀 모든 맵의 나무·집·바위도 실사 사진으로 나온다.

## 조작

- **카메라**: 영화(천천히 도는 시점) · 옆에서 · 기관실 · 위에서 — 버튼으로 전환
- **속도**: 0.5배 · 1배 · 1.7배
- **소리**: 소리 켜기를 누르면 사용자가 고른 곡 **Cobblestone Railway**(6분, 루프 재생)와 잔잔한 바람 소리가 나온다. 곡 파일을 못 불러오면 기존의 바람의나라·테일즈위버 분위기 패드 사운드로 자동 대체된다.
- **멈추기/계속 가기**, 경과 시간 타이머, 재생 중 화면 꺼짐 방지

## 기술

- 실시간 3D 렌더링: [Three.js](https://threejs.org/) r128 (리포에 자체 호스팅, `assets/three.min.js`)
- 청크 단위로 생성되는 무한 지형, 굽이치는 레일 경로 함수 기반 배치
- 실시간 햇빛과 그림자, 안개, 하늘 그라데이션, 컨셉 간 색상 블렌딩
- 단일 HTML 파일들로 구성 (빌드 과정 없음)

## 배포 방식 (2026-10-29부터, 소스 보호)

이 리포는 비공개 소스 원본이다. 공개 리포(sidebatch/healing-train)에는 소스를 직접 push하지 않는다.

1. 여기서 소스를 수정·커밋하고 `origin`(이 비공개 리포)에 push
2. `cd tools/deploy && npm install && node build-deploy.mjs` — 난독화된 배포본이 `dist-deploy/`에 생성됨 (부팅·파일 검증 내장)
3. `dist-deploy/`에서 커밋해 공개 리포로 push (그 폴더 자체가 배포 전용 git 리포)

공개 주소 https://sidebatch.github.io/healing-train/ 는 변하지 않는다.
